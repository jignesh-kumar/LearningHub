# C++ Learning Notes

This folder contains small C++ examples and notes for core language concepts.

## Suggested order
- Function pointers
- Initializer lists
- Local classes
- Anonymous classes
- Typeid and runtime checks
- Compilation basics
- STL containers and `emplace_back`

## Revision strategy
- Read the example
- Run it locally
- Note the key takeaway in one sentence
- Compare it with similar concepts
