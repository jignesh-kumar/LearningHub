# Learning Roadmap

This repository is designed for hands-on learning, revision, and interview preparation. The best way to use it is to study one concept at a time, run the example, then review the summary and practice questions.

## Suggested study order

1. Start with the basics
   - Python fundamentals
   - C++ syntax and control flow
2. Build core programming concepts
   - functions, classes, inheritance, polymorphism
3. Learn language-specific features
   - initializer lists, function pointers, local classes
4. Move to STL and practical patterns
   - vectors, emplace_back, standard containers
5. Revise for interviews
   - compare concepts, explain trade-offs, and practice examples

## Recommended revision pattern

For each topic:
- Read the explanation once
- Run the code example
- Write the concept in your own words
- Try to explain it aloud without looking at the notes
- Answer the practice questions
