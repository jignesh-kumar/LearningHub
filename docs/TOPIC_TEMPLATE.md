# Topic Template

Use this structure when adding a new learning topic.

## 1. Concept summary
Explain the idea in one or two short paragraphs.

## 2. Why it matters
List why the concept is useful in real code.

## 3. Syntax or key idea
Include the important code pattern or rule.

## 4. Example
Add a small working example.

## 5. Output or expected behavior
Mention what the example should print or do.

## 6. Common mistakes
List pitfalls that learners often run into.

## 7. Interview-style questions
Add 2 to 4 quick questions for revision.

## 8. Next steps
Link to related topics or suggested exercises.
